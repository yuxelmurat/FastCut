# FastCut — Gizlilik Politikası

*Son güncelleme: 2026-08-07*

FastCut, resim kesme (crop) işlemini tamamen **kullanıcının kendi bilgisayarında, çevrimdışı** olarak gerçekleştiren bir masaüstü uygulamasıdır.

## Toplanan Veri

FastCut hiçbir kişisel veri, kullanım istatistiği veya resim içeriği toplamaz, saklamaz ya da internet üzerinden herhangi bir sunucuya göndermez. Uygulama internet bağlantısı gerektirmez.

## Erişilen Sistem Kaynakları

- **Dosya sistemi:** Yalnızca kullanıcının sağ tıkladığı resim dosyasını okur ve kesilmiş kopyayı aynı klasöre kaydeder.
- **Windows Kayıt Defteri (Registry):** Sağ tık bağlam menüsüne "FastCut ile Kes" seçeneğini eklemek için `HKEY_CLASSES_ROOT\SystemFileAssociations\image\shell\FastCut` anahtarını oluşturur. Bu işlem yalnızca kullanıcı onayıyla (UAC / yönetici izni istemi) ve kullanıcının açık isteği üzerine ("Sağ tık menüsüne eklensin mi?" sorusuna Evet denildiğinde) gerçekleştirilir.

## Üçüncü Taraflarla Paylaşım

Hiçbir veri üçüncü taraflarla paylaşılmaz, çünkü hiçbir veri toplanmaz veya iletilmez.

# FastCut — Privacy Policy (English)

*Last updated: 2026-08-07*

FastCut is a desktop application that performs image cropping entirely **locally, offline**, on the user's own computer.

## Data Collection

FastCut does not collect, store, or transmit any personal data, usage statistics, or image content to any server. The application does not require an internet connection.

## System Resources Accessed

- **File system:** Reads only the image file the user right-clicks on, and saves the cropped copy in the same folder.
- **Windows Registry:** Adds a "FastCut ile Kes" entry to the right-click context menu by creating the `HKEY_CLASSES_ROOT\SystemFileAssociations\image\shell\FastCut` key. This only happens with explicit user consent (UAC / administrator prompt) and only when the user agrees to the "Add to right-click menu?" prompt.

## Third-Party Sharing

No data is shared with third parties, because no data is collected or transmitted.
